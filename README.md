# The DSA Way: A Hero's Journey

A cinematic, game-inspired DSA GI learning quest through the Five Whys and root-cause analysis.

## Live site

[Open The DSA Way: A Hero's Journey](https://roshan-d-patel-8.github.io/dsa-way-hero-journey/)

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages build

```bash
npm run build:pages
```

The `main` branch is deployed automatically through GitHub Actions.
